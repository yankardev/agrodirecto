# AgroDirecto Web

Frontend Angular del proyecto AgroDirecto.

Estructura por funcionalidades:

- `core`: servicios globales, guards, interceptors y modelos compartidos.
- `shared`: componentes reutilizables.
- `modules/auth`: autenticación.
- `modules/catalog`: catálogo.
- `modules/cart`: carrito.
- `modules/orders`: pedidos.
- `modules/farmer`: panel del agricultor.
- `modules/admin`: administración.
